# HOW TO WRITE A NEW BLOG POST
# ================================
# Every blog post is a Markdown file inside the _posts/ folder.
#
# STEP 1 — Name the file correctly:
#   Format:  YYYY-MM-DD-your-post-title.md
#   Example: 2026-06-04-thoughts-on-machine-learning.md
#
# STEP 2 — Copy the template below into your new file.
#
# STEP 3 — Fill in your content. Write in Markdown.
#
# STEP 4 — Save the file. Push to GitHub. Done.
#   Git commands:
#     git add _posts/your-post-file.md
#     git commit -m "New post: Your Post Title"
#     git push
#
# The post will appear on /blog/ automatically.
